## ReEDS Water & Climate Input Processing
This folder contains the scripts and source data used to generate some of the waterclimate files in ReEDS (https://github.com/ReEDS-Model/ReEDS/tree/main/inputs/waterclimate). 

> **Note:** These scripts have not been maintained and may require some modification to be run successfully.

## Output File Map
| **Output File** | **Generated By** |
| --------------- | ---------------- |
| `tg_rsc_cspagg_tmp.csv` | `tg_rsc_cspagg_tmp_csv_maker/csp_class.py` |
| `water_with_cons_rate.csv` | `water_with_cons_rate_csv_maker/water_with_cons_rate.py` |
| `cost_cap_mult.csv` | created manually using `water_with_cons_rate_csv_maker/inputs/REEDS_Input.xlsm` |
| `cost_vom_mult.csv` | created manually using `water_with_cons_rate_csv_maker/inputs/REEDS_Input.xlsm` |
| `heat_rate_mult.csv` | created manually using `water_with_cons_rate_csv_maker/inputs/REEDS_Input.xlsm` |

## Scripts
- `tg_rsc_cspagg_tmp_csv_maker/csp_class.py`:
  - creates `tg_rsc_cspagg_tmp.csv` file which maps directly to [`ReEDS/inputs/waterclimate/tg_rsc_cspapp_tmp.csv`](https://github.com/ReEDS-Model/ReEDS/blob/main/inputs/waterclimate/tg_rsc_cspagg_tmp.csv)

- `water_with_cons_rate_csv_maker/water_with_cons_rate.py`: Processes the heritage ReEDS's input datafile (`REEDS_Input.xlsm`) and extracts essential water usage rate from the "Cooling Water" sheet. It extracts CSP's water usage rate as well to create the output file `water_with_cons_rate.csv`. 
  - Since `csp-ns` and `csp-ws` have same date and `csp-ws` is treated differently in ReEDS, this script just extracts `csp-ns`'s data for simplicity. `csp-ws`'s data should be populated by the help of `csp-ns`'s data.
